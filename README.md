# 💰 systemFinance  

**systemFinance** é um projeto Open Source para a criação de um sistema **CRM** voltado para **gerenciamento de clientes**, **monitoramento de dívidas** e **geração de relatórios financeiros**. O sistema oferece uma interface intuitiva e funcionalidades avançadas para facilitar o controle financeiro e a tomada de decisões.  

## 🚀 Funcionalidades  

- 📋 **Gerenciamento de Clientes**: Cadastro, edição e exclusão de clientes.  
- 💳 **Monitoramento de Dívidas**: Registro de débitos, vencimentos e status de pagamento.  
- 📑 **Geração de Relatórios**: Relatórios detalhados sobre clientes, transações e status financeiro.  
- 🔐 **Autenticação e Segurança**: Controle de acesso com autenticação segura.  
- 🌐 **Dashboard Interativo**: Interface amigável para visualização e gerenciamento de dados.  

## 🛠️ Tecnologias Utilizadas  

- **Frontend**: React.js  
- **Backend**: Python (FastAPI)  
- **Banco de Dados**: PostgreSQL / Firebase Firestore  
- **Autenticação**: Firebase Authentication / JWT  
- **Estilização**: Tailwind CSS  
- **Outros**: Axios, Redux, Chart.js (para gráficos e relatórios)
